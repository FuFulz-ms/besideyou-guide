## 资料来源与时效

2026-11-21（北京时间）重新核对了线上官方手册、玩家可见工具，以及当时正在运行的生产版本的关键规则。

| 核对来源 | 适用范围 |
| --- | --- |
| 生产版本及公开手册 | 心动卡池 9／10 的价格、保底、贴纸；农场作物、料理、偷菜额度；普通探索和组队次数；角色等级战力、异能实际加成与商店永久战力；宠物蛋品质适用范围、孵化时间、升级；海图航次和回收；古墓、蜃楼入口和锻造 |
| 线上官方手册或对应公开工具 | 签到、社交、书架、长安玩法、安全屋各级加成；玩家实际奖励和进度看本人回执 |
| 已公开的历史记录 | 拍拍南瓜旧档期等。历史资料用于理解机制，活动是否开放、轮换货架、账号与房间状态需要实时核对 |

此 Skill 汇总玩家可见规则。每次涉及当期可用内容时，优先对照游戏当前页面、公告或对应的公开规则。
